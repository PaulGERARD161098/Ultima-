# Mémoire Léo — Lexique de dictée vocale

> Déformations récurrentes de la reconnaissance vocale de Paul.
> Léo vérifie chaque message dicté contre ce lexique et l'enrichit à chaque
> nouvelle déformation détectée (entendu → compris).

| Entendu | Compris |
|---|---|
| Fatima, le climat, tu ultima | Ultima |
| Clio | Léo |
| Marco agent, Macron agent | master agent |
| Marc Audi | (amorce déformée — contexte : « master agent ») |
| Montreuil | mon travail |
| mon mécontent professionnel | mes contacts professionnels |
| outil d'automne TED | outils dédiés |
| en otarchie | en autarcie |
| Superbase | Supabase |
| maître en relation | mettre en relation |
| le projet « tantot » | le projet [créé] tantôt (= le projet Supabase existant) |
| Adam Elesh, à Dramalèche, Adramalèche, Adram Elech, Adramelèche | ADRAMELECH (quadrant idées) |
| Florilège Didet | florilège d'idées |
| Laurent Merlin | Leroy Merlin (enseigne de bricolage) |
| ils sont des dix | (déformation — contexte : « attribue-lui un nom ») |
| la vanvaille | l'avant-veille |
| la pause (contexte chantier) | la pose |
| on stocke à moi | mon stock à moi |
| Humladric, Imladric, Imladrik | IMLADRIK (quadrant dév. perso) |
| Traveller, Traveler | TRAVELER (quadrant réseau — un seul L, rappel Paul 2026-07-16) |
| directive EB, macro-directive | discipline : boucler avant d'avancer + capitaliser sur l'existant |
| Renault Boost, Renoboost | Renoboost IA (socle rémunérateur = chantiers + installations à domicile ; ligne de base du benchmark ADRAMELECH) |
| mon Starlog / Claude Normal | son journal de dév. perso dans l'app Claude standard (modèle d'IMLADRIK) |

Règle : en cas de doute sur un mot qui change le sens d'une instruction,
reformuler et demander — jamais deviner avant une action irréversible.
