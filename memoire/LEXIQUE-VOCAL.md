# Mémoire Léo — Lexique de dictée vocale

> Déformations récurrentes de la reconnaissance vocale de Paul.
> Léo vérifie chaque message dicté contre ce lexique et l'enrichit à chaque
> nouvelle déformation détectée (entendu → compris).

| Entendu | Compris |
|---|---|
| Fatima, le climat, tu ultima | Ultima |
| Clio | Léo |
| Marco agent, Macron agent | master agent |
| Marc Audi | (amorce déformée — contexte : « master agent ») |
| Montreuil | mon travail |
| mon mécontent professionnel | mes contacts professionnels |
| outil d'automne TED | outils dédiés |
| en otarchie | en autarcie |
| Superbase | Supabase |
| maître en relation | mettre en relation |

Règle : en cas de doute sur un mot qui change le sens d'une instruction,
reformuler et demander — jamais deviner avant une action irréversible.
