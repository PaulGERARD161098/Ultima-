# Appeler les compétences

## Demander le résultat

Exprimer le travail attendu et, si utile, le nom de la compétence. Choisir selon le besoin et les accès réels.

## Exemples d’appel

| Besoin | Formulation à réutiliser |
|---|---|
| Séquences email | Utilise emails pour préparer un parcours de relance de devis. |
| Révision éditoriale | Utilise copy-editing pour rendre ce mail naturel et précis. |
| Suivi commercial par email | Utilise email-writer pour reprendre cette discussion commerciale. |
| Composition éditoriale | Utilise composition-editoriale avec presentations-claires pour composer cette présentation. |
| Pitch sourcé | Utilise pitch-source pour préparer le récit de cette présentation. |
| Design d’interface | Dans l’environnement de développement, charge frontend-design pour cette interface. |
| Thèmes graphiques | Charge theme-factory pour proposer un thème à ce support. |
| Art génératif | Charge algorithmic-art pour explorer un visuel génératif. |
| Tests d’application web | Charge webapp-testing pour vérifier ce parcours web. |
| Création de skills | Dans le dépôt source, charge .claude/skills/skill-creator/SKILL.md pour préparer une compétence. |
| Thèmes de forum | Utilise discourse-theme-authoring pour modifier ce thème. |
| Blocs de forum | Utilise discourse-block-authoring pour préparer ce bloc de forum. |
| Marketing de communauté | Utilise community-marketing pour préparer une stratégie de communauté. |
| Présentations claires | Utilise presentations-claires pour créer une présentation à partir de ce brief. |
| Approches croisées | Utilise anti-pattern avec les angles utilisateur, preuve commerciale et opérateur. |

## Choisir l’environnement

Dans Work, appeler la compétence personnelle par son nom ou le sélecteur de skills. Sur mobile, ouvrir Plugins puis Skills pour consulter les compétences installées.

Dans un environnement de développement ayant le dépôt, charger le SKILL.md indiqué et ses références utiles. Les copies de rédaction conservent leur licence et leur version amont. Vérifier la version du dépôt réellement chargée.

Dans Léo sur le site, le catalogue oriente la demande. Le résumé projeté ne remplace pas les guides complets. Si le guide ou les outils ne peuvent pas être chargés, Léo doit le dire. Cliquer sur une fiche n’exécute pas un moteur et n’accorde aucun droit.

## Combinaisons utiles

- Devis : emails pour le parcours, email-writer pour un échange individuel, copy-editing pour la révision.
- Présentation : presentations-claires avec pitch-source et composition-editoriale.
- Communauté : community-marketing pour le parcours, puis les compétences de thème et de blocs pour les changements techniques.
- Contrôle : anti-pattern pour croiser les approches et une vérification adaptée au livrable.

## Remettre à jour

Après chaque ajout ou retrait demandé, remesurer les environnements, actualiser le registre et régénérer les fiches. Ne changer la date qu’après une mesure réelle. Aucune routine permanente n’est activée.
